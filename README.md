## 📌 About the Project

**BingePlay** is an end-to-end **SQL & Data Analytics project** that simulates a real-world Indian OTT streaming platform. The project focuses on analyzing user behavior, subscriptions, revenue, content performance, device usage, ratings, binge-watching patterns, and potential churn signals using **MySQL and Python**.

The project is designed from the perspective of a **Data Analyst**, where real-world business questions are converted into analytical SQL queries to generate meaningful insights from relational data.

BingePlay contains **5 relational tables** covering users, subscriptions, shows, watch sessions, and ratings. The project includes **12 business-focused analytical problems**, progressing from SQL fundamentals to advanced concepts such as **JOINs, subqueries, CTEs, window functions, `ROW_NUMBER()`, `LAG()`, self-joins, NULL handling, and gaps-and-islands analysis**.

### 🎯 Key Focus Areas

* 📊 Streaming and user behavior analytics
* 💰 Revenue and subscription analysis
* 👥 User signup and engagement analysis
* 📺 Content performance analysis
* 📱 Device usage and watch-session analysis
* ⭐ Rating and content-quality analysis
* 🍿 Binge-watching behavior detection
* 🔄 Subscription upgrade analysis
* 📉 Churn signal identification

The project demonstrates how **SQL and Python can be combined to transform structured streaming data into actionable business insights**.

**Tech Stack:** MySQL • SQL • Python • Pandas • Jupyter Notebook • SQLAlchemy • PyMySQL
